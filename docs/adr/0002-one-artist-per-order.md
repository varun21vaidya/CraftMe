# One Artist per Order

A Cart holds Listings from a single Artist, and adding another Artist's Listing asks the Buyer to start a new Cart. This was first needed because Buyers paid Artists directly (ADR 0001). It was kept when CraftMe began collecting payments (ADR 0004) because it keeps each Order equal to one parcel from one Artist, with one set of stages, one Payout line and one Review. Multi-Artist carts would need an Order split into per-Artist parts with their own stages, Refunds and Payouts.
