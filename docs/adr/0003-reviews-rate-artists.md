# Reviews rate Artists, not Artworks

A Review rates an Artist as a seller (quality, packing, communication), once per Order, from Received for 30 days, and appears only after the Admin approves it. Most Listings are Originals that sell once, so a review attached to an Artwork would help no future Buyer; the Artist is what a Buyer can choose again. The existing code reviews Artworks; the rebuild changes that on purpose.
