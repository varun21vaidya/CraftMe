Design reference · demo build

CraftMe screens

Every screen of the marketplace as plain HTML, so you can point at a detail and ask for a change.

1. Open a screen

Each card below is one page. Pages link to each other the way the real app will.

2. Switch states

The dark bar at the bottom of every screen lists its states: empty, error, loading, each Order stage, and so on.

3. Turn on Labels

Labels outlines every named component. Ask for changes like S09 · Order summary · show the Artist's name.

4. Light and dark

The moon button in the bar switches themes. Both are designed, not inverted.

The look in one view

A gallery wall: cool paper-grey ground, white mats around every piece of art, museum wall labels for titles and prices, and one ultramarine accent. Money, dates and codes use a monospaced face, like catalogue numbers.
